# Iconic Tools - Variant3AbstractInteractiveHeroV2

A stunning, interactive 3D hero component featuring particle-based text formation, shooting stars, and a physics-based gold mouse trail.

## Features

- **Particle Text System** - ICONIC text forms from 25,000-60,000 gold particles
- **Organic Shimmer** - Heat haze effect using shader-based noise
- **Shooting Stars** - Automatic gold shooting stars
- **Physics-Based Mouse Trail** - 100 gold particles follow the cursor
- **Post-Processing** - Bloom, noise, and vignette effects
- **Responsive Design** - Adapts to different screen sizes
